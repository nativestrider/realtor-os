# Listing Copy (stub)

Read `property.json` and any photos in `images/`. Write polished marketing copy to `listing.md`:

- `# Headline` — one line, under 80 characters
- `## Description` — 2–3 paragraphs highlighting key selling points
- `## Bullets` — 5–8 feature bullets

Use only facts from `property.json` and visible photo context. Do not invent amenities.
